# Spicy Bot 🌶️ (Real Pinterest)

Uses Playwright to scrape real images from Pinterest.

## Setup

1. Open CMD in this folder
2. Run:
```cmd
npm install
```
(This also downloads Chromium – takes 1-2 minutes the first time)

3. Create .env:
```cmd
copy .env.example .env
notepad .env
```
Add your DISCORD_TOKEN and CLIENT_ID

4. Run:
```cmd
node index.js
```

First /spicy may take 5-8 seconds while it opens Pinterest.
